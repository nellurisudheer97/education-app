# EduForge Frontend

Enterprise-style React frontend for an educational platform with role-aware dashboards, course management, lesson delivery, and quiz workflows.

## Local Setup

1. Install dependencies:
   - `npm ci`
2. Start development:
   - `npm start`
3. Run quality checks:
   - `npm run lint`
   - `npm run test:ci`
   - `npm run build`

## Environment Variables

- `REACT_APP_API_BASE_URL` (optional): API base URL, defaults to `http://localhost:8080/api`.
